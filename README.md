# My Web Tools (Mobile & Desktop)

Nền tảng công cụ tiện ích cá nhân miễn phí, siêu nhẹ, chạy 100% Client-Side trên trình duyệt web, tối ưu đặc biệt cho điện thoại di động (iPhone & Android).

🌐 **Truy cập trực tuyến qua GitHub Pages:**  
👉 **`https://amin7410.github.io/my_own_APP_TOOLs/`**

---

## 🛠️ Danh sách các công cụ hiện có

1. 📷 **Document Scanner** (`/tools/doc-scanner/`):
   - Chụp 1 ảnh hoặc chụp hàng loạt liên tục bằng camera.
   - Thuật toán tự động căn chỉnh tài liệu: *Màu nét (Magic Color)*, *Trắng đen (B&W Scanner)*, *Thang xám (Grayscale)*.
   - Bộ chỉnh sửa trang toàn màn hình (xoay 90°, tăng/giảm độ sáng, tương phản, ngưỡng tách nét).
   - Đổi tên tài liệu linh hoạt.
   - Xuất PDF chuẩn (tích hợp Web Share API để chia sẻ ngay qua AirDrop, Zalo, Files, Mail), xuất ZIP hoặc tải ảnh JPG.

2. 📑 **PDF Viewer** (`/tools/pdf-viewer/`): Đọc và phóng to thu nhỏ file PDF mượt mà.
3. 📊 **Excel Viewer** (`/tools/excel-viewer/`): Đọc bảng tính Excel `.xlsx`, `.csv` nhanh chóng.

---

## 📱 Mẹo sử dụng trên điện thoại (iPhone & Android)

- **Trên iPhone (Safari):** Mở link -> Bấm nút **Chia sẻ** (hình vuông mũi tên lên ở dưới đáy Safari) -> Chọn **Thêm vào MH chính (Add to Home Screen)**. Ứng dụng sẽ hoạt động full màn hình như app native!
- **Trên Android (Chrome):** Mở link -> Bấm menu 3 chấm góc trên -> Chọn **Cài đặt ứng dụng** hoặc **Thêm vào màn hình chính**.
